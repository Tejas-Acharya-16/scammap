The call

    How it works

    • Scam calls follow scripts in fixed steps. We wrote 4 of them down: digital arrest, bank KYC and OTP, task jobs and UPI refunds, 5 steps each.
    • A Naive Bayes model reads each line you add and scores every step. A hidden Markov model then follows the call forward through the script, so one unclear line does not throw it off, and it can say which step usually comes next.
    • Both run in this browser. The model file is downloaded once; what you type is never sent anywhere. No LLM, no outside service.
